## 📌 About the Project

**EcoSort AI** is a sustainability-focused project that explores how Artificial Intelligence can be used to support **waste segregation and responsible waste management**.

The project was developed as part of the **1M1B AI for Sustainability Virtual Internship**, combining AI concepts with a real-world environmental problem.

The idea is to make waste classification easier and more accessible by using technology to help identify different types of waste and encourage proper disposal.

---

## 🎯 Problem Statement

Improper waste segregation is one of the major challenges in effective waste management.

When different types of waste are mixed together, recyclable and reusable materials become harder to recover, while organic and hazardous waste can create additional environmental problems.

EcoSort AI explores how AI-based classification can assist users in identifying waste categories and making better disposal decisions.
